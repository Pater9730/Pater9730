📦 Proyecto - Gestor de pedidos

API RESTful desarrollada con ASP.NET Core para la gestión de personas y pedidos. Implementa autenticación y autorización mediante ASP.NET Core Identity, JWT y Refresh Tokens, con una arquitectura en N capas basada en principios SOLID.

Incluye middleware para el manejo global de excepciones, métodos de extensión para el mapeo entre DTOs y entidades, y consultas con Entity Framework Core y LINQ. Incorpora optimizaciones de acceso a datos mediante AsNoTracking e Include, persistencia de personas y pedidos, y el cálculo del Top 5 de personas con mayor gasto durante los últimos 30 días.

Tecnologías: C#, ASP.NET Core, Entity Framework Core, SQL Server, Identity, JWT, Refresh Tokens, LINQ, SOLID.

🔗 Repositorio: https://github.com/Pater9730/Proyecto-Gestor-Pedidos
