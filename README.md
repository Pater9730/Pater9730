📦 Proyecto - Gestor de pedidos

API RESTful desarrollada con ASP.NET Core para la gestión de personas y pedidos. Implementa autenticación y autorización mediante ASP.NET Core Identity, JWT y Refresh Tokens, junto con una arquitectura en N capas basada en principios SOLID.

Incluye manejo global de excepciones mediante middleware, mapeo de DTOs a entidades mediante métodos de extensión y consultas con Entity Framework Core y LINQ. También incorpora consultas optimizadas con AsNoTracking e Include, persistencia de personas y pedidos, y cálculo del Top 5 de personas con mayor gasto durante los últimos 30 días.

Tecnologías: C# · ASP.NET Core · Entity Framework Core · SQL Server · Identity · JWT · Refresh Tokens · LINQ · SOLID · N-Capas.
